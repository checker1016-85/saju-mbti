## 기능 상세

### 3대 추천+선택 시스템

직업 · MBTI · 에니어그램 모두 동일 패턴:

| | 추천 (사주 기반 자동) | 선택 (사용자 직접) |
|---|---|---|
| **직업** | 스탯 매칭 상위 3개 카테고리 + ★뱃지 | 모달에서 15카테고리 130+직업 전체 |
| **MBTI** | 축별 % 점수, 차이 15% 이내면 양쪽 추천 | 축 토글 버튼 또는 16개 직접 클릭 |
| **에니어그램** | 십성 가중치 상위 3유형 | 1~9 클릭 → 양쪽 날개 자동 |

### MBTI 계산 로직

```
E/I = (식신+상관+편재+정재) vs (편인+정인+비견+겁재)
S/N = (편재+정재+편관+정관) vs (식신+상관+편인+정인)
T/F = (편관+정관+비견+겁재) vs (식신+상관+편재+정재)
J/P = (정관+정재+정인) vs (편관+편재+편인+상관)
```

차이 15% 이내인 축은 양쪽 모두 추천 범위에 포함.

### 에니어그램 계산 로직

십성 가중치 × 십성 카운트 → 9유형 점수:

| 유형 | 핵심 십성 |
|------|-----------|
| 1번 완벽주의자 | 정관 + 정인 |
| 2번 조력자 | 식신 + 정재 |
| 3번 성취자 | 편재 + 편관 |
| 4번 개인주의자 | 상관 + 편인 |
| 5번 탐구자 | 정인 + 편인 |
| 6번 충성가 | 비견 + 정관 |
| 7번 열정가 | 식신 + 편재 |
| 8번 도전자 | 편관 + 겁재 |
| 9번 평화주의자 | 비견 + 정재 |

메인 선택 시 날개(±1) 자동: 5번 → 4w5 / 5w6

### 스탯 5개 + 방사형 레이더 4종

**스탯**: 재물력, 놀기력, 리더력, 학습력, 독립력 (십성 카운트 × 14 + 격국/강약 보정)

**레이더 4종** (각 5축):

| 레이더 | 축 | 색상 |
|--------|-----|------|
| 체력·멘탈 | 체력, 멘탈력, 회복력, 인내력, 스트레스내성 | 레드 |
| 사회성 | 리더십, 소통력, 협업력, 매력, 공감력 | 퍼플 |
| 재능·두뇌 | 창의력, 분석력, 실행력, 전략력, 직관력 | 민트 |
| 재물·야망 | 수익감각, 투자감각, 야망, 안정추구, 모험도 | 골드 |
